# ⚡ Neon Vibe Clicker — Неоновый Вайб-Кликер

Стильный, быстрый и залипательный киберпанк кликер с неоновым дизайном, процедурным звуком и прокачкой. Работает прямо в браузере — без установки и внешних зависимостей.

---

## 🚀 Как запустить игру

1. Просто откройте файл [`index.html`](file:///c:/Users/kzvla/OneDrive/Documents/Вайб%20кликер/index.html) двойным кликом в любом браузере (Chrome, Edge, Firefox, Safari, Яндекс.Браузер).
2. Или запустите локальный сервер:
   ```bash
   python -m http.server 8080
   ```
   и перейдите по адресу `http://localhost:8080`.

## 🎮 Ключевые фичи и механики

### 1. Неоновый интерактивный кликер
* **Интерактивное ядро (Vibe Core)** с неоновыми кольцами, отдачей и динамической подсветкой.
* **Спецэффекты при нажатии**: фонтан искр на Canvas, расширяющиеся ударные волны и вылетающие неоновые цифры очков.
* **Комбо-разгон & ГИПЕР-ВАЙБ**: частые клики разгоняют комбо-полосу. При заполнении шкалы включается **режим Лихорадки (Fever)** с множителем **x3.5** к кликам и **x2** к пассивному доходу!
* **Критические клики**: возможность прокачать шанс нанести сокрушительный x5 крит с золотым фейерверком.

### 2. Магазин прокачки
* **🏭 Авто-вайб (Пассивный доход)**:
  * ☕ **Кофе «Espresso Neon»** — бодрит по утрам (+0.5 вайб/сек)
  * ⚡ **Энергетик «Cyber Rush»** — мощный буст таурина (+4 вайб/сек)
  * 🎮 **Видеокарта «RTX 5090 Ti»** — аппаратный майнинг вайба (+32 вайб/сек)
  * 🧠 **Нейросеть «DeepVibe 4.0»** — генерация настроения нон-стоп (+260 вайб/сек)
  * 🌌 **Квантовый Сервер «Q-Vibe»** — мультивселенский вайб (+2,100 вайб/сек)
  * 🛸 **Сингулярность Вайба** — перезагрузка матрицы (+18,000 вайб/сек)
* **⚡ Усилители клика (Ручная мощь)**:
  * Неоновый курсор, тактильные свитчи, разгон частоты, Вайб-Резонанс (+% от пассивного дохода к клику) и критические импульсы.

### 3. Звуковой синтвейв-движок (Web Audio API)
* 100% процедурный синтез звука — не требует загрузки mp3/wav файлов и работает офлайн.
* Звуки кликов динамически повышают свою тональность по пентатонической гамме при быстром тапе (создает приятный музыкальный ритм).
* Кнопка включения фонового аналогового синтвейв-пэда (**🎵 Вайб-фон**).

### 4. Сохранение и оффлайн-прогресс
* Автоматическое сохранение в `localStorage` каждые 4 секунды и при закрытии вкладки.
* **Оффлайн-доход**: пока вкладка закрыта, автокликеры продолжают накапливать вайб, и при следующем заходе появляется окно наград.
* Возможность экспорта и импорта кода сохранения, а также сброса прогресса.

### 5. Дополнительно
* **💎 Летающий Глитч-Кристалл**: периодически пролетает через экран — поймайте его для мгновенного бонуса или режима x3 ускорения!
* **🏆 12 Ачивок** с тост-уведомлениями.
* Полная адаптивность под смартфоны и ПК.
