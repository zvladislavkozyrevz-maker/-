# 🖤 Мастер-Промпты для генерации артов «Альтушка-Кликер»

Набор готовых к копированию промтов для нейросетей (**Midjourney v6.1**, **DALL-E 3**, **Stable Diffusion XL / Flux**) по всем 5 уровням эволюции персонажа в строгом соответствии с вашим стилем и задумкой (от обычной серой мышки до ультра-заряженной роскошной альтушки 160 см / 140 кг).

---

## 🎨 Единый визуальный стиль (Style Guide)
Для идеальной гармонии в кликере все изображения должны иметь:
- **Стиль**: Высококачественная 2D аниме/вебтун иллюстрация, четкий контур (bold clean lineart), мягкие цифровые тени (cel shading), эстетика ночного города/спальников.
- **Композиция**: Персонаж на среднем/поясном плане (medium shot, waist-up), смотрит в камеру, чтобы по ней было удобно и приятно тапать по центру экрана.
- **Соотношение сторон**: `--ar 16:9` для десктопного фона кликера или `--ar 9:16` для вертикального мобильного режима.
